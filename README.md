# بوت نشر المحتوى الإسلامي لقنوات Telegram

> README عربي مبني على قراءة ساكنة للملفات الموجودة في المستودع. لا يوجد README حالي، والمصدر البرمجي محفوظ في `islamic_bot.zip` فقط. لم يُشغّل المشروع أو اختباراته ولم تُثبّت اعتمادياته؛ لذلك فخطوات الإعداد أدناه إرشادية وغير مجرّبة، ولا تمثل تأكيدًا لقابلية التشغيل.

## نبذة

يحتوي الأرشيف على تطبيق Python يستخدم `aiogram` لبوت Telegram يهدف إلى إعداد ونشر محتوى القرآن والأحاديث والأذكار في القنوات أو المجموعات. يتضمن المصدر واجهة إدارية لإدارة القنوات والجدولة وبعض إعدادات المحتوى، ويستخدم قاعدة بيانات غير متزامنة عبر SQLAlchemy.

هذا وصف لما يظهر في الملفات، وليس ضمانًا لاكتمال الميزات أو صحة المحتوى أو جاهزية المشروع للاستخدام الإنتاجي.

## ما يظهر في المصدر

- أوامر `/start` و`/help` و`/admin`.
- إنشاء مهام نشر دورية بفواصل زمنية، واختيار نوع المحتوى المستهدف: `quran` أو `hadith` أو `adhkar`.
- إعداد منشورات آيات القرآن، مع محاولة إرفاق التفسير والصوت عند توافرهما.
- إعداد منشورات للأحاديث والأذكار؛ وتظهر في المصدر خدمة للأذكار تعتمد على مصدر خارجي مع ملف محلي احتياطي محدود.
- أدوات إدارية ظاهرة لإضافة القنوات وإزالتها، وإدارة المهام، واختيار قارئ ونمط خط، وإرسال منشور يدوي، وعرض إحصاءات النشر.
- تخزين بيانات المستخدمين والقنوات والمهام والإعدادات والإحصاءات في نماذج قاعدة البيانات.

بعض هذه المسارات قد تكون غير مكتملة أو معطوبة؛ يلزم اختبارها ومراجعتها قبل الاعتماد عليها.

## محتويات الأرشيف

ملف `islamic_bot.zip` هو الملف الوحيد المتعقب في جذر المستودع. ويضم، من بين الملفات، `main.py` ونقاط الدخول والمعالجات والخدمات والجدولة و`database.py` و`config.py` و`requirements.txt` و`data/adhkar.json`. لا توجد نسخة مفكوكة من المصدر ضمن المستودع.

## المتطلبات والإعداد

ملف `requirements.txt` يحدد الإصدارات التالية:

- `aiogram==3.3.0`
- `SQLAlchemy==2.0.23`
- `aiosqlite==0.19.0`
- `APScheduler==3.10.4`
- `aiohttp==3.9.1`
- `tenacity==8.2.3`

لا يحدد المستودع إصدار Python أدنى أو أعلى، ولا يتضمن تعليمات نشر أو إعداد قاعدة بيانات موثقة. يحتاج تشغيل المسارات التي تتصل بالخدمات الخارجية إلى اتصال شبكي. لا تنفّذ أوامر الإعداد على بيئة إنتاج قبل مراجعة الأمان والتبعيات ومصدر البيانات.

خطوات الإعداد التالية مستنتجة من بنية الأرشيف وملف التبعيات ونقطة الدخول، ولم تُجرّب:

```bash
unzip islamic_bot.zip -d islamic_bot
cd islamic_bot
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

قبل أي محاولة تشغيل، راجع `config.py` محليًا. يستورد التطبيق إعداداته من هذا الملف، ولا يظهر في المصدر دعم مباشر لقراءة ملف `.env` أو متغيرات بيئة. لا تضع أي رمز أو كلمة مرور أو قيمة إعداد حساسة في المستودع أو في سجل الأوامر. لا توجد طريقة آمنة ومؤكدة لتجهيز إعدادات صالحة من الملفات الحالية وحدها، لذا لا تُتابع إلى التشغيل قبل إزالة أي بيانات اعتماد ثابتة واستبدالها بآلية أسرار مناسبة.
